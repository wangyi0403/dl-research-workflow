# 投稿前图表检查

按当前目标期刊、项目约定和图的用途检查；不适用项记为 N/A 并说明原因。期刊的实际要求优先于这里的常见做法。`scripts/check_figure.py` 只检查部分文件属性，不能替代布局、科学表达和稿件中最终显示效果的审阅。

## 尺寸与分辨率

- 在目标稿件的实际显示尺寸检查文字、线条和图例可读性。建议从接近最终尺寸的 `figsize` 开始；允许在 Word/LaTeX 中缩放矢量图，缩放后重新核验字号、线宽与视觉层级。
- 明确导出尺寸与稿件显示尺寸。PDF 的 `--width-in / --height-in` 核验可见页面（CropBox）的导出物理尺寸，容差为 0.1 in；包含旋转与 UserUnit。使用 `bbox_inches='tight'` 会改变导出尺寸，需以实际文件为准。
- 位图用同组参数指定最终显示尺寸，检查两轴的有效 DPI；不指定时仅使用 DPI 元数据。扩大显示尺寸可能使分辨率不足。DPI 阈值按期刊和图像类型设置，300 DPI 只是脚本默认值。
- SVG/EPS 的物理尺寸当前不能由该脚本完整检查；使用合适的独立工具核验并记录结果，不能把 UNKNOWN 当作 PASS。

## 文件格式与字体

- 线条与文字优先矢量 PDF/SVG，图像按期刊要求使用 PNG/TIFF 等格式；混合图可包含位图，但需要核验最终显示分辨率。
- JPEG 是有损格式，数据图优先无损格式；照片是否可用 JPEG 由用途和期刊规定，不作统一禁令。
- 核验字体嵌入、缺字和跨设备显示。Matplotlib 的 `pdf.fonttype=42` 是常见选择，不能推导出所有期刊只允许 TrueType。Type 3 字体需按期刊规则检查，不能一概断言其一定模糊或不可用。
- 字体、最小字号、子图标签格式遵循当前期刊要求或已有项目约定；不要根据出版商名称套用固定字体。未给定要求时使用可读、一致的少量字体。
- PDF 字体脚本包含页面和 Form XObject 的资源检查，但不核验实际字形可读性，也不测量最终稿件内的字号；这些仍需视觉检查。

## 视觉与语义

- 颜色、线型、marker 或直接标签能支持区分；需要时用灰度或色觉模拟检查。保留已有可访问的项目配色，不强制指定色板。
- 连续色阶与顺序/发散语义匹配；发散中心由参照值决定，不一律设为 0。需要读数的颜色编码配清晰的 colorbar、标签和适用单位。
- 坐标标签、单位、对数/归一化等变换清晰，精度与数据相称。
- 柱长通常需要有意义的零基线；折线、散点、分布图允许合理限制范围，但不能误导幅度比较。断轴必须明确标记。
- 图例、子图标签和刻度不遮挡数据、不越界，多面板的样式一致；不同坐标范围需清楚标识。
- 小样本或分布形状重要时呈现观测值或分布；不要让均值柱掩盖关键差异。双轴、分类变量连线、3D 等可能误导的编码必须有合理用途和清晰保护措施。
- 按图的实际类型查阅 [viz_pitfalls.md](viz_pitfalls.md)，将其中经验性阈值和例子作为审阅提示，不转化为所有图通用的硬门槛。

## 不确定性与统计

- 有误差棒、区间、阴影或箱线时，图注明确其定义（例如 SD、SEM、置信区间、分位数，以及箱线须的规则）和相关样本量/分析单位。
- 存在重复、配对、聚类或随机种子时说明不确定性基于哪个层级；不得把相关观测当成独立重复。
- 只有进行了推断检验时才要求交代检验方法、假设及适用的多重比较校正；只有使用显著性符号时才要求解释符号。描述性区间不自动要求 p 值或显著性检验。
- 没有误差棒不自动构成错误。确定性量、总体描述或单次观测按其含义呈现，并说明限制；需要支持变异性或推断的主张时必须有相应证据。

## 中文或混排图

- 需要中文时可使用 `setup_style(lang='zh')`，检查实际字体是否存在、汉字与负号是否正确渲染。
- 字体回退、数字与变量字体遵循项目和期刊约定，不统一强制 Times New Roman；图中文字语言遵循论文和用户要求。

## 文件审计与最终验收

```bash
python scripts/check_figure.py figs/*.pdf \
    --width-in 3.5 --height-in 2.625 --strict
python scripts/check_figure.py figs/*.png \
    --min-dpi 300 --width-in 3.5 --height-in 2.625 --strict
```

参数仅是示例，应按实际要求调整。文件检查状态：

| 状态 | 含义 | strict 退出码 |
|---|---|---|
| PASS | 该脚本支持且适用的文件检查未发现问题 | 0 |
| WARN / INFO | 需判断或说明的提示，仍需审阅 | 0 |
| UNKNOWN | 必需检查未执行或不受支持，例如缺依赖 | 3 |
| FAIL | 文件损坏或已核验要求不满足 | 2 |

多文件同时存在 FAIL 和 UNKNOWN 时返回 2。退出码 0 不表示整份清单或视觉 QA 已通过；不使用 `--strict` 时退出码也不能用于合规判定。

在绘图脚本仍持有 Matplotlib Figure 时调用 `visual_qa.audit_layout(fig)` 检查缺字、越界与刻度重叠。`visual_qa.py <file> --preview ...` 仅渲染文件预览，不执行 Figure 布局审计。最后查看预览和稿件中的实际尺寸，对照源数据确认结论；在 `docs/10_figure_report.md` 记录文件审计、视觉检查、未完成项及适用例外。
