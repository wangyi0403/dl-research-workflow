# 期刊情报卡片模板

```yaml
journal: [期刊全称]
publisher: [出版社]
issn: [ISSN]
website: [投稿页面 URL]

scope: |
  [期刊 aims and scope 摘要，200 字以内]

author_guidelines:
  page_limit: [页数限制]
  abstract_format: [structured / unstructured / 字数限制]
  figure_specs: [分辨率/格式/色彩要求]
  reference_style: [引用格式]
  special_requirements: [数据可用性声明/伦理声明/作者贡献声明...]

recent_papers_analyzed: [精读数量，Stage 1C 完成后填写]

acceptance_bar:
  method_novelty: [从近2年论文推断：方法要到什么程度才被接受]
  experiment_depth: [实验消融/baseline 强度要求]
  common_rejections:
    - [典型退稿原因 1]
    - [典型退稿原因 2]

review_cycle:
  average_time: [平均审稿周期]
  acceptance_rate: [接受率]

fit_assessment:
  scope_match: [high / medium / low]
  rationale: [为什么投/不投这本]

ranking: [1st / 2nd / 3rd choice]
```
