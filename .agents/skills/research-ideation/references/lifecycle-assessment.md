# Idea 生命周期评估

每个 idea 有明确的时间窗口。评估自己能否在窗口内完成，避免投入注定做不完的方向。

## Idea 类型与生命周期

| Idea 类型 | 生命周期 | 适合条件 | 注意事项 |
|-----------|---------|---------|---------|
| **应用型研究**（方法改进） | 3-6 个月 | 编码扎实、快速执行 | 博士主力类型 |
| **基础理论研究** | 6-12 个月 | 数学/理论基础扎实、能深入思考 | 风险高，需理论功底 |
| **跨学科研究** | 6-9 个月 | 有其他学科背景 | 投稿窗口可能在 HCI 等领域 |
| **前沿探索型**（LLM Agent 等） | 3-9 个月 | 理论+实验兼具、自主学习能力强 | **竞争激烈，窗口短，被抢先风险高** |
| **数据密集型**（新 Benchmark） | 6-12 个月 | 数据分析能力强、能处理大规模数据 | 构建数据集耗时 |
| **创新性技术研究** | 12 个月以上 | 基础扎实、愿挑战现有理论 | 博士长期项目 |

## 快速判断

```
1. 这个 idea 是什么类型？
2. 预计多久能完成？（编码 + 实验 + 论文）
3. 你的可用时间是多少？
4. 时间不匹配 → 调整 idea 范围或换方向
```

## 关键原则

- **热门方向要快**：LLM Agent 等领域 3-6 个月没投出去就可能过时
- **慢不是低质量**：基础理论需要时间，但不能无限拖延
- **匹配自己能力**：编码快选应用型，理论强选基础型
- **博士生注意**：毕业论文需要 2-3 个相关工作，选互补型 idea 组合
