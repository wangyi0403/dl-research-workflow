# Idea 五维生成框架

不要拿着"斧头"（解决方案）去找"木头"（研究问题）。从已有问题出发，从五个维度系统性地寻找切入点。

| 维度 | 核心目标 | 常用切入策略 | AI+铁道/工程 示例 |
|------|---------|-------------|-----------------|
| **更高 Higher** | 提升准确率与效果 | 信息/模态补全、反馈驱动优化、错误根因分析 | 多源传感器融合提升检测精度；引入空间上下文减少误报 |
| **更快 Faster** | 提升效率与降低开销 | 缓存与经验复用、并行与解耦、提前终止与动态路由 | 轻量预筛 + 重模型按需调度；多 Agent 并行推理 |
| **更强 Stronger** | 提升鲁棒性与泛化能力 | 抗噪与容错设计、异常恢复机制、解耦表征泛化 | 跨线路/跨光照条件泛化；传感器故障时降级运行 |
| **更省 Cheaper** | 降低数据与标注/部署成本 | LLM 自动数据合成、主动学习与人机协同、知识蒸馏 | 标注稀缺场景用 LLM 生成伪标签；大模型蒸馏到边缘设备 |
| **更广 Broader** | 跨界与通用性扩展 | 跨领域思想移植、抽象与统一框架 | NLP 可解释性方法移植到轨道检测；多任务统一框架 |

## 使用方式

每个维度生成 2-3 个 idea，总计 8-12 个候选。生成时：
1. 明确 idea 属于哪个维度
2. 一句话描述核心机制
3. 指出它跟现有方法的本质区别
4. 标注它依赖的关键假设（linchpin）
