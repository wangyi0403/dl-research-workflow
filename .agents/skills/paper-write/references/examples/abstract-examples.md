# Abstract Examples Index

## Pattern use

Use only when it fits the current article, evidence and reader. Wording, contribution counts, graphics and sentence counts are illustrative, not requirements. Published-study details belong to those examples and do not supply facts for this manuscript. The section guides and verified venue requirements govern actual writing.


All abstract example cites should point to the local files below.

1. Pattern 1 (Challenge -> Contribution)
`Pattern 1: Introduce the technical challenge, then use one to two sentences to present the technical contribution that solves the challenge.`
`references/examples/abstract/template-a.md`
2. Pattern 2 (Challenge -> Insight -> Contribution)
`Pattern 2: Introduce the technical challenge, then use one to two sentences to present the insight for solving the challenge, and then one sentence to present the technical contribution that implements this insight. (Personally recommended.)`
`references/examples/abstract/template-b.md`
3. Pattern 3 (Multiple Contributions)
`Pattern 3: When there are multiple technical contributions, describe each contribution together with its technical advantage.`
`references/examples/abstract/template-c.md`
