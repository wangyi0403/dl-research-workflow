# Cover Letter Writing Patterns

> Generic patterns. Adapt to your manuscript and target journal.

## A Compact Default Structure

Adapt this sequence to the target journal's current requirements; it is not a mandatory paragraph count.

### P1: What + To Whom
One sentence. State: (a) what you're submitting, (b) the title, (c) the target journal.

### P2: The Problem
What real problem does this solve? Ground it concretely:
- Scale: how many data points / how frequent / how costly
- Current practice gap: what happens now vs what should happen
- Why now: what changed that makes this solvable today

Keep it tight. This isn't the introduction — it's the elevator pitch.

### P3: The Obstacle + Question
What makes this problem hard? State the obstacle specifically. Then state the research question. If possible, abstract the question beyond your domain so the editor sees broader relevance.

Test: Would a researcher in a related field understand why this question matters?

### P4: Contributions
Present the manuscript's verified contribution set. Number the items only when it improves readability. Each contribution:
- Has a conceptual name (not "Module A")
- States a mechanism or finding
- Includes a specific number when available
- Is verifiable from the manuscript

### P5: Fit + Close
Why THIS journal specifically? Show you've done your homework:
- Reference specific recent work from this journal only when it is verified and genuinely relevant
- Name the sub-area within the journal's scope
- Explain how your work extends the conversation already happening there

### Declarations

Use only declarations actually confirmed by the responsible author or a recorded policy. Unknown items remain explicitly unconfirmed in drafts; a template is not consent.
- Original, not published elsewhere, not under simultaneous consideration
- All authors approved
- Competing interests disclosed (or none)
- AI usage disclosure if applicable

## Common Mistakes

| Don't | Do |
|-------|-----|
| "This fits the scope of your journal" (generic) | "This extends the line of work on [X] that has appeared in this journal, including [cite specific paper]" |
| "We propose a novel framework" (vague) | "We find that [mechanism]. To leverage this, we build [system] that achieves [number]." |
| Summarize the abstract | State the contribution and its significance. The editor reads the abstract separately. |
| "Future work will..." (hollow) | Omit. The cover letter is about THIS manuscript. |
| Over-claim beyond what the paper supports | Every claim in the CL must match what's demonstrable in the manuscript. |

## Length
Follow the journal's stated limit. If none is given, keep the letter concise and normally near one page; preserve the contribution and fit arguments before optional context.
