## 模型选择与最终测试使用规则

| 项目 | 冻结的协议与依据 |
|---|---|
| 验证集与选模 | 验证数据 ID；超参数搜索范围、预算；主选模指标、早停和检查点选择规则 |
| 最终测试 | 测试数据 ID；何时运行、允许的评估范围；测试结果不用于选择模型、种子、阈值或报告子集 |
| 比较与报告冻结 | 主指标、比较对象、分析单位、种子和纳入/排除规则；结果表与统计定义引用 06 |
| 测试暴露或协议偏离 | 在 07 记录接触结果的时间、影响与处置；依据 WORKFLOW 重验受影响 Gate |

模型与分析规则冻结后再执行最终测试。若测试反馈影响了后续设计，该分析标为探索性；验证性结论须使用未参与选择的独立数据或预先规定的有效评价设计。重复测试、公开 benchmark 调参或无法取得独立数据时，明确报告限制，不能把已暴露测试集继续描述为独立验证。

## 基线与公平性控制

记录各比较方法的可用输入、预训练资源、调参范围与预算、选模规则及硬件/推理成本口径。不同资源条件须有理由并在解释中保留，不以只精调本方法的比较证明方法优势。

## 指标、不确定性与统计检验

| 项目 | 预定设计与依据 |
|---|---|
| 分析单位与独立性 | 个体、事件、场景、站点或运行；独立样本数；时间/空间/重复测量依赖与聚类 |
| 重复与汇总 | 种子、数据划分或测量重复分别代表什么变异；配对关系、分组、权重及合并规则 |
| 估计与误差条 | 效应或比较量、单位；SD / SE / 置信 / 可信 / 预测区间；计算方法和适用假设 |
| 检验与决策 | 与论断相符的检验或比较规则；多重比较与缺失/异常值处置；适用时的等效/非劣效界值 |
| 实际价值 | 能影响科学或工程判断的差异、成本与时效条件；不以显著性阈值替代实际意义 |

同一对象的帧、时间点或技术重复不自动增加独立样本数；单次结果不补造区间。统计不显著或区间重叠不能直接写为相同、无效或等效。具体分析遵循研究设计，不强制每项结果使用同一检验。

## 条件性评价契约

仅在适用时填写：生成式/Agent 评价记录参考世界或真值源、可观测输入、冲突优先级、排除规则、unknown/abstain 处理和错误类型；PINN/数值模型记录解析/FEM/FDM/验证求解器基准、边界条件、误差、采样稳定性和成本；工程代理模型记录校准/覆盖率、OOD 与不确定性如何影响实际决策。详细判据见 `$experiment-plan` 的 `references/evaluation-extensions.md`。

物理—数据耦合或预警任务分别核验过程/守恒与求解误差、观测符合度、跨区域/时间迁移、校准及端到端时效；粗细网格和加速结果在可比精度与硬件口径下解释。数据融合注明观测可用时刻、缺测及校正路径，避免未来信息泄漏。只执行能影响本项目论断或决策的适用检查，不把业务演示成功当普遍有效性。
