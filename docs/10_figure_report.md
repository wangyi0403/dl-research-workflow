# 10 图表报告

## 图的清单、叙事角色与目的

| Figure ID | 角色（动机 / 方法总览 / 实验 / 支持） | Claim 或 Chain ID | 一句话 takeaway | 数据或代码来源 | 论文位置 | 状态 |
|---|---|---|---|---|---|---|

并非每篇论文都必须包含每一种角色。

选择载体以读者任务为准：精确离散值用表，趋势/分布/权衡用图，简单事实可直接写正文；数据流图不替代需要交代状态与分支的算法。说明图中要读的具体单元、区域或条件及其支持的判断，避免一图多表只重复同一结论。

## 核心图的角色特定检查

- 动机：使用真实问题或失败示例，并与全文 Running Example 一致；不得编造示例。
- 方法总览：输入、输出和数据流明确；节点命名与 `04_methodology.md`、`09_paper_plan.md` 一致。
- 实验：图型与变量匹配，坐标和不确定性诚实；本表的 takeaway 必须受对应证据支持，正文承担科学解释，短 caption 与 Notes 保留独立阅读所需信息。
- 定性案例：记录随机、分层、典型或边界案例的选择规则与总体分母；示例解释行为，不单独证明群体频率、优胜或泛化。
- 三维或物理示意：核对其他必要视角、几何/物理含义及可编辑源文件；单视角外观吻合不自动证明结构或机理正确。

## 图题、注释和正文分工

按 [WRITING_STANDARD.md](WRITING_STANDARD.md) 与 02 的适用编辑要求检查；长题不机械变成单行，保留必要面板说明、单位、统计定义与符号解释。

| 图 / 表 ID | 短题与面板说明 | Notes / 阅读信息位置 | 长解释的正文位置 | 适用要求 ID | 当前版本与状态 |
|---|---|---|---|---|---|

核对图/表、短题和 Notes 在最终尺寸下保持关联；编号、面板及引用一致。篇幅与数量引用 09 的唯一预算表，不另设配额。

## 尺度、不确定性、色彩、字体与印刷尺寸检查

柱形长度通常使用有意义的零基线；限制坐标范围、断轴、归一化或对数尺度必须可见并解释。图不能只靠颜色区分系列，且应在稿件实际显示尺寸下复核。配色遵循当前期刊和项目语义，不强制通用的 Proposed/Baseline 颜色。
