# Project collaboration / 项目协作

Use the current host's approved assistant and tools. The project owner chooses any external collaborator, information-sharing scope, request budget and stopping condition. An unspecified model is not automatically selected or purchased.

按当前宿主使用已批准的助手与工具。外部协作者、共享材料范围、请求预算与停止条件由项目负责人确定，不自动选购未指定模型。

Batch the actual question with necessary evidence, frozen decisions and requested output. Record the handoff in `00_start.md`; verify returned claims against source material before adopting them into the relevant numbered record.

交接包含实际问题、必要证据、冻结决定与所需输出，引用00中的授权。返回意见经来源核验后写入对应阶段记录，不另建竞争状态入口。

Keep one owner for shared registries and scheduling. Separate reviewers and editors when their independence affects a scientific decision. Use multiple agents only when useful, supported and allowed by the current task; this template does not override host delegation rules.

共享台账和调度保留唯一负责人；科学判断需要独立性时分清审阅与编辑。多 Agent 协作须实际可用、对任务有益且符合当前授权，模板不覆盖宿主的分派限制。

Existing project authorization is reusable within the same scope. New recipients, paid resources, uploads or publication require the relevant authorization. Monitoring is configured only when requested and bound to a real run or pending request.

范围内复用已有效的授权；新增接收方、费用、上传或发布需要对应授权。监督仅在用户要求且绑定真实运行或待回复请求时建立。
