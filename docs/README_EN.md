The current state, authority, next gate and resumption links live in `00_start.md`.
Read only the records relevant to the present stage. Each record owns a particular
piece of the research rather than duplicate every decision.

| Record | Owns |
|---|---|
| [00 Start](00_start.md) | Question, scope, permissions, budget, stage and next action |
| [01 Data analysis](01_data_analysis.md) | Data identity, units, splits, leakage, quality and transformations |
| [02 Journal scouting](02_journal_scouting.md) | Verified venue requirements and fit |
| [03 Idea report](03_idea_report.md) | Question candidates, novelty, claim/evidence identities, Gate A |
| [04 Methodology](04_methodology.md) | Formal problem, assumptions, mechanism and design |
| [05 Experiment plan](05_experiment_plan.md) | Frozen comparisons, metrics, inclusion and failure rules, Gate B |
| [06 Result tables](06_result_tables.md) | Expected runs, table schema, units and statistical meanings |
| [07 Experiment tracker](07_experiment_tracker.md) | Run decisions, deviations, resumption and supervision bindings |
| [08 Analysis](08_analysis.md) | Results, contradictions, claim updates and Gate C |
| [09 Paper plan](09_paper_plan.md) | Central answer, reader path, argument/figure map and Gate D |
| [10 Figure report](10_figure_report.md) | Data provenance, reproducibility and visual checks, Gate E |
| [11 Pre-submission audit](11_pre_submission_audit.md) | Versioned citation, numerical, manuscript and review checks, Gate F |
| [12 Release readiness](12_release_readiness.md) | Local release inventory, rights, verification and unresolved requirements |

The detailed record forms and original workflow are shared Chinese-language
project documents; the English workflow and writing guide explain their contracts.
Use the project's chosen language for filled scientific records and manuscripts.
