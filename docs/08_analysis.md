# 08 分析

## 协议完整性与分析单位

说明实验单位、该单位的样本量、独立性假设、被排除的运行和协议偏离。分析单位不明确时，不得声称优胜或统计显著。

## 主要结果与不确定性

至少传递估计值、不确定性区间或变异性、样本量、统计检验或比较规则、有意义时的效应量，以及确切的结果产物。矛盾统计结果在来源解决前必须隔离；不得只选择有利计算。

解释误差条捕获的变异及计算假设，区分独立样本与技术/时序重复、配对与非配对设计。统计显著不替代效应大小或实际价值；未达到显著性不证明无效或等效，等效结论须有相应设计与界值。不同分析集合导致数值差异时说明分母与纳入条件，不默默统一数字。

## 负结果或空结果
