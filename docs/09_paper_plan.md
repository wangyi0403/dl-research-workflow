## 论文类型与叙事轴

| 类型 | 主叙事轴 | 当前选择与理由 |
|---|---|---|

类型可在 Gate D 前基于证据调整，不在 Stage 0 永久锁定。

## 中心论断与贡献链

概括目标读者要获得的中心回答、实际贡献对象、比较/认识差异、适用条件和决定性证据。按研究类型选择必要的支持论据，不要求固定贡献数或每种论文都提出新方法；论断当前状态与允许措辞引用 03，解释和结果引用 08。

## 工程—科学叙事阶梯（工程研究必填）

在下方叙事追踪矩阵中检查这条叙事链：现场问题的规模与后果 → 既有工程瓶颈 → 可复用的测量/物理/推断问题 → 受证据支持的新认识 → 方法载体 → 工程与科学双重验证。通过 Claim / Evidence / Chain ID 引用 03、04 和 08，不在此重新定义贡献链、方法机制或结果判断。

如机制命题尚未被数据支持，须在论文计划中将其写作待检验假设，不能作为既成贡献。

## 叙事追踪矩阵

| 读者问题与叙事项 | Claim ID / Chain ID | 决定性证据及精确读数 | 最强有据替代解释 / 缺口 | 章节与表达载体 | 主文 / 补充位置及理由 | 允许措辞来源 |

这是论文内容与证据位置的唯一追踪表；上方中心论断、叙事阶梯与章节安排只作概括和引用。允许措辞引用 03 的当前论断版本，表述发生实质变化时回到该记录核验。

按读者需要定位值、理解关系、运行过程或检查证明，选择正文、表、图、公式、算法或形式命题；无独立用途不重复展示。主文保留决定性证据及改变理解的协议、比较条件与边界；完整设置、证明和次要诊断可置补充材料，但不得隐藏反证。缺证据时引用 05 的最小区分实验及正/负/不确定处置，或收窄论断，不另建竞争账本。

完整起草后复核标题、摘要、引言、主要图表与结论的承诺一致性；压缩先处理通用铺垫、项目时序、重复定义和重复展示，保留必要推理、引文、比较条件及真实边界。
